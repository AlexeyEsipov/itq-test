# Сервисы по работе с документами

Проект представляет собой backend-сервис для работы с документами.
Он состоит из двух сервисов - reestr и util.
### Сервис reestr выполняет следующие операции: 
 - создать документ;
 - извлечь документ с историей изменений;
 - вернуть список документов по списку внутренних id;
 - принять список документов (список внутренних id) и согласовать их;
 - принять список документов (список внутренних id) и утвердить их;
 - поиск документов с фильтрацией по статусу, автору, датам создания, датам изменения;
 - проверка корректности конкурентного утверждения документа (утверждения документа из разных потоков).

### Сервис util выполняет следующие операции:
 - отправляет в сервис reestr N запросов на создание N документов; 
 - проверяет базу данных на наличие черновиков документов и отправляет пакеты таких документов на согласование в сервис reestr;
 - проверяет базу данных на наличие согласованных документов и отправляет пакеты таких документов на утверждение в сервис reestr;

## Запуск сервисов
Для запуска выполните команду 
```cmd
docker compose up -d
```
После поднятия контейнеров сервис reestr будет доступен на адресу http://localhost:8100 , сервис util будет доступен по адресу http://localhost:8081,
база данных PostgreSQL доступна на порту http://localhost:5455 , имя базы - itqreestr.

#### Оба сервиса имеют подключенный swagger 
После запуска сервисов проверить их работоспособность можно с использованием Swagger:
- сервис util : http://localhost:8081/swagger-ui/index.html
- сервис reestr : http://localhost:8100/swagger-ui/index.html
